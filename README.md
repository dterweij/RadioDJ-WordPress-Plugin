# RadioDJ-WordPress-Plugin
RadioDJ WordPress Plugin (Refactored from an old Plugin)
Show information about your radiostation on your website.
Now playing, requests, top lists and so on.

Tested with Wordpress up to 6.9
Tested upto PHP 7.3.25
Does have a Dutch and English translation using POT/MO/PO files.
Only Dutch and English are the updated ones.

[RadioDJ website](https://radiodj.ro/).
