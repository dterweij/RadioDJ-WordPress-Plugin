# RadioDJ WordPress Plugin

A WordPress plugin for displaying information about your radio station on your website.

The plugin has been **refactored from an older version** and provides several features, including:

* 🎵 **Now Playing** information
* 📻 **Upcoming** and recently played tracks
* 🎤 **Request** functionality
* 🏆 **Top lists**
* And more

## Compatibility

* **WordPress:** Tested up to version **6.9**
* **PHP:** Tested with **PHP 7.3.25**

> **Note:** PHP 7.3 is no longer supported by current Wordpress releases. Compatibility with newer Wordpress versions may vary depending on your WordPress environment.

## Translations

The plugin includes translations for:

* 🇳🇱 Dutch
* 🇬🇧 English

Translations are provided using **POT, PO, and MO files**.

Currently, only the **Dutch and English translations** have been updated.

## RadioDJ

This plugin is designed to work with [RadioDJ](https://radiodj.ro/?utm_source=chatgpt.com).

This project is a refactored version of an older RadioDJ WordPress plugin. The goal is to provide an easy way to integrate RadioDJ information and functionality into a WordPress website.
